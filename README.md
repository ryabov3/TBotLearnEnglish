# 🎓 TBotLearnEnglish

Telegram-бот для тренировки **английского произношения** в школе: учитель создаёт темы и задания, ученик сдаёт ответы голосом или видео, преподаватель проверяет работы и отслеживает статистику, а администрация управляет ролями и рассылками — всё через удобное кнопочное меню внутри Telegram.

## 🚀 Старт, регистрация и навигация

- Единственная команда бота — **`/start`** (команды `/menu`, `/profile` и `/admin` убраны — вся навигация выполняется через кнопки главного меню).
- **Защита незарегистрированных пользователей:** пока пользователь не завершил регистрацию через `/start`, на любое сообщение, команду или нажатие кнопки бот отвечает уведомлением с просьбой пройти регистрацию.
- **Выбор роли при регистрации:** новый пользователь самостоятельно выбирает, кем он является — **👨‍🎓 Ученик** или **👨‍🏫 Учитель** (пользователи, указанные в `FOUNDERS_ID` или `ADMINS_ID`, получают соответствующие роли автоматически).
- **Валидация имени и фамилии:** при регистрации и редактировании профиля принимаются только русские или латинские буквы (допускается один дефис для двойных имён/фамилий), длина от **2 до 50 символов**, без цифр и спецсимволов, с автоматической капитализацией.
- **Компактная сетка кнопок:** панели и меню выстроены в удобной 2-колоночной сетке.

## 🛡 Роли и права доступа

| Роль | Доступный функционал |
| :--- | :--- |
| **Ученик (`student`)** | Новые темы, темы в процессе, отправка аудио/видео ответов, история сдач и оценок, профиль и статистика (streak, всего выполнено, рекорд за день) |
| **Учитель (`teacher`)** | Управление классами и группами, добавление/удаление учеников, конструктор тем с медиа и черновиками, удаление тем, проверка ответов, статистика по группам и ученикам, профиль |
| **Администратор (`admin`)** | Весь функционал учителя + кнопка **«🛠 Панель администратора»** в главном меню (назначение/снятие учителей, просмотр иерархии учителей/классов/групп/учеников, досье пользователей, рассылки, личные сообщения, отвязка от группы, бан/разбан) |
| **Основатель (`founder`)** | Все права администратора + **назначение и снятие администраторов** через админ-панель; защищён от изменения роли или блокировки другими администраторами |

Кнопка **«🛠 Панель администратора»** отображается в главном меню только у пользователей с ролью `admin` и `founder`.

## 🧑‍🎓 Функции ученика

- **Главное меню:**
  - 📝 **Новые темы** — темы, по которым ещё нет ни одного сданного задания.
  - ⏳ **В процессе** — начатые темы с прогрессом вида `(2/5)`.
  - ✅ **Выполненные** — последние 10 сданных работ с оценкой или статусом «На проверке» и комментарием учителя.
  - 👤 **Мой профиль** — ФИО, `@username`, роль, класс/группа, статистика и кнопка смены имени (с валидацией).
- **Выполнение заданий:** пошаговое прохождение темы, просмотр вложений учителя (фото, голос, аудио, видео, кружок, документ), проверка требуемого формата ответа (только аудио / только видео / любой), предпрослушивание с выбором «Отправить учителю» или «Записать заново».
- Доступ к темам открывается после того, как учитель добавит ученика в класс/группу.

## 👨‍🏫 Функции учителя

- **Классы и ученики:** создание связок «класс + группа», добавление учеников по `@username`, просмотр списков классов и отвязка учеников с пагинацией.
- **Конструктор тем:** создание темы с несколькими подзаданиями, опциональными медиа-примерами, выбором формата ответа ученика, предпросмотром всей темы, множественным выбором групп для публикации и сохранением черновика в **Redis** (черновик сохраняется даже после перезапуска бота).
- **Удаление тем:** выбор темы с пагинацией и подтверждением (удаляются все задания темы и связанные ответы учеников).
- **Проверка и статистика:** просмотр непроверенных ответов по группам и заданиям, выставление оценки от 1 до 5 с комментарием, раздел «Проверенные задания», средний балл по каждому заданию и по группе в целом, а также успеваемость каждого ученика.

## 👑 Панель администратора и основателя

Доступна через кнопку **«🛠 Панель администратора»** в главном меню (для ролей `admin` и `founder`):

- **Управление ролями:** назначение и снятие учителей (`admin` и `founder`), а также **назначение и снятие администраторов** (только `founder`).
- **Мониторинг:** иерархия «Учителя → Классы → Группы → Ученики», досье по любому пользователю и отвязка учеников от групп.
- **Коммуникации и модерация:** массовые рассылки ученикам или учителям, личные сообщения конкретному пользователю, бан и разбан.

## 🗂 Архитектура проекта

```text
TBotLearnEnglish/
├── bot.py                  # Точка входа, настройка логирования, RedisStorage и роутеров
├── config/config.py        # Загрузка настроек из .env (MySQL, Redis, Proxy, Graylog, роли)
├── database/
│   ├── engine.py           # Асинхронный движок SQLAlchemy (aiomysql)
│   ├── models.py           # Модели User, StudyGroup, Task, Submission
│   └── cache.py            # Слой кэширования Redis с инвалидацией и fallback на MySQL
├── handlers/               # Обработчики по ролям (student.py, teacher.py, admin.py)
├── keyboards/              # Inline-клавиатуры по ролям (student.py, teacher.py, admin.py)
├── lexicon/lexicon.py      # Единый словарь всех текстов, кнопок, команд и описаний
├── middlewares/            # LoggingMiddleware и RegistrationCheckMiddleware
├── filters/                # Фильтры ролей (role.py) и валидации имени/фамилии (name.py)
├── states/states.py        # Группы состояний FSM
├── migrations/             # Миграции Alembic
├── Dockerfile              # Сборка контейнера на Python 3.12 + uv
└── docker-compose.yml      # MySQL, Redis, Adminer, Graylog (OpenSearch + MongoDB), Bot
```

## ⚡ Оптимизация через Redis

В проекте используются две отдельные базы Redis:

- **БД 0 (`REDIS_DB=0`) — кэш частых запросов к MySQL:** кэшируются профили пользователей (для middleware, фильтров ролей и меню), списки групп учителя, отдельные группы, списки учеников в группах, задания классов/групп, отдельные задания, список учителей и рассчитанная статистика групп. При любом изменении данных кэш точечно инвалидируется, а при временной недоступности Redis бот автоматически откатывается к MySQL.
- **БД 1 (`REDIS_FSM_DB=1`) — `RedisStorage` для FSM:** состояния диалогов и черновики тем учителя сохраняются между перезапусками контейнера.

## 🐳 Запуск через Docker

### 1. Файл `.env`

Создайте `.env` в корне проекта (он исключён из сборки через `.dockerignore` и передаётся в контейнер через `env_file` в `docker-compose.yml`):

```env
BOT_TOKEN=your_telegram_bot_token

# Числовые Telegram ID через запятую (можно оставить пустыми или не указывать)
FOUNDERS_ID=123456789
ADMINS_ID=

DB_USER=root
DB_PASSWORD=root
DB_HOST=db
DB_PORT=3306
DB_NAME=tbot_db

# Параметры Redis (значения ниже используются по умолчанию)
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_DB=0
REDIS_FSM_DB=1
REDIS_PASSWORD=
REDIS_TTL=600

OPENSEARCH_PASSWORD=StrongPassword123!

# Оставьте пустыми, если прокси для Telegram API не нужен
PROXY_LOGIN=
PROXY_PASSWORD=
PROXY_HOST=
PROXY_PORT=

GRAYLOG_HOST=graylog
GRAYLOG_PORT=12201
```

### 2. Запуск контейнеров

```bash
docker compose up -d --build
```

Поднимутся сервисы:

| Сервис | Назначение |
| :--- | :--- |
| 🤖 **bot** | приложение Telegram-бота (при старте автоматически применяются миграции Alembic) |
| 🗄️ **db** | MySQL 8 |
| ⚡ **redis** | Redis 7 (кэш данных и хранилище FSM) |
| 🌐 **adminer** | веб-интерфейс к БД — `http://localhost:8080` |
| 📊 **graylog**, **mongodb**, **opensearch** | централизованные логи — `http://localhost:9000` |

### 3. Полезные команды

```bash
# Просмотр логов бота в реальном времени
docker compose logs -f bot

# Пересобрать и перезапустить только бота после правок кода
docker compose up -d --build bot

# Остановить все сервисы
docker compose down

# Остановить и удалить тома (включая данные БД и Redis)
docker compose down -v
```

## ⚠️ Заметки

- Токен **`BOT_TOKEN`** выдаётся в **BotFather** и не должен попадать в публичный репозиторий.
- В **`FOUNDERS_ID`** и **`ADMINS_ID`** указываются только числовые Telegram ID (через запятую). Если оставить их пустыми или убрать из `.env`, бот запустится штатно без ошибок.
- Для получения роли `founder` после добавления своего ID в `FOUNDERS_ID` достаточно перезапустить контейнер бота и нажать `/start`.
