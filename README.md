# 🎓 TBotLearnEnglish

Telegram-бот для тренировки **английского произношения**: учитель выдаёт темы и задания, ученик сдаёт ответы голосом или видео, преподаватель проверяет работы и ведёт статистику — всё внутри Telegram.

---

## 🧑‍🎓 Функции ученика

### 🚀 Старт и регистрация

- **`/start`** — первый вход: создание записи в боте, проверка на блокировку.
- **Знакомство** — пошаговый ввод **имени** и **фамилии** с подтверждением («Всё верно» / «Изменить»).
- Автоопределение роли: обычный пользователь получает роль **ученик** (администраторы из `ADMINS_ID` — свою роль).

### 🏠 Главное меню

- **`/menu`** — сброс активных шагов и открытие панели по текущей роли.
- **Панель ученика** (кнопки):
  - 📝 **Новые темы** — темы, по которым ещё нет ни одного сданного задания.
  - ⏳ **Темы в процессе** — темы, где есть и выполненные, и невыполненные задания (с прогрессом вида «2/5»).
  - ✅ **Выполненные задания** — последние **10** сдач с кратким статусом (оценка или «на проверке»).
  - 👤 **Мой профиль** — карточка профиля и статистика.

> Доступ к темам возможен только если учитель **добавил ученика в класс/группу**. Иначе бот сообщит, что группа ещё не назначена.

### 👤 Профиль

- **`/profile`** или кнопка **«Мой профиль»**:
  - имя, фамилия, `@username`, роль;
  - **класс** и **группа**;
  - **статистика**: дней подряд с заданиями (**streak**), всего выполненных заданий, максимум заданий за один день.
- **✏️ Изменить имя** — смена имени и фамилии (с кнопкой отмены).

### 📝 Работа с заданиями

- Выбор темы → цепочка заданий **по порядку** внутри темы.
- Просмотр **темы**, **названия**, **текста задания**.
- Просмотр **вложения от учителя** (если есть): фото, голос, аудио, видео, видеосообщение (кружок), документ.
- Указание **требуемого формата ответа**:
  - 🎤 только **голосовое / аудио**;
  - 📹 только **видео / видеокружок**;
  - 🤷‍♂️ **любой** из перечисленных медиа-форматов.
- Отправка ответа **только медиа** (голос, аудио, видеокружок, видео); текст и прочие типы отклоняются с подсказкой.
- **Проверка формата** под выбранное учителем ограничение (аудио / видео / любой).
- Перед отправкой: **«Отправить учителю»**, **«Записать заново»** или выход в меню (прогресс по теме сохраняется).
- После сдачи: предложение **продолжить тему** (следующее задание) или **пауза / в меню**.
- При завершении **всех** заданий темы — поздравление и возврат в меню.

### ✅ История сдач

- Список выполненных работ с привязкой к теме и заданию.
- Детальный просмотр: описание задания, **оценка** (или «ещё не проверено»), **комментарий учителя**.

### 🛡 Ограничения

- Заблокированные администратором пользователи при старте получают сообщение о **блокировке** и не проходят дальше.

## 👨‍🏫 Функции учителя

*(Роль **учитель** назначается администратором. Пользователи из `ADMINS_ID` имеют расширенные права и тот же учительский функционал в панели.)*

### 🏠 Панель учителя

- Вход из общего меню (после назначения роли).
- Кнопка **«Продолжить создание темы»** появляется, если есть **черновик** темы (незавершённое создание).

### ➕ Классы и ученики

- **Создать группу** — ввод **названия класса** и **названия группы** (создаётся запись «класс + группа» за преподавателем).
- **Добавить ученика** — выбор группы → ввод **`@username`** (ученик должен хотя бы раз запустить бота).
- **Удалить ученика** — выбор группы → список с пагинацией → **отвязка** ученика от класса/группы (поля класса/группы очищаются).
- **Список классов** — пагинация по вашим группам → просмотр **списка учеников** в выбранной группе (ФИО и `@username`).

### 📝 Создание и публикация заданий

- **Создать задание** — пошаговый мастер **одной темы** с **несколькими подзаданиями**:
  - название **общей темы** (лимит длины в боте);
  - для каждого подзадания: **название**, **текстовое описание**;
  - опционально: **медиа-пример** (фото, видео, аудио, голос, видеокружок, документ) или **«Пропустить медиа»**;
  - выбор **формата ответа ученика**: только аудио, только видео, или любой из двух.
- После каждого подзадания:
  - ➕ **Добавить ещё задание**;
  - ✏️ **Переделать последнее задание**;
  - 👀 **Предпросмотр темы** — как увидит ученик (текст + вложения по порядку);
  - ➡️ **Выбрать группы для отправки** — множественный выбор групп (переключение галочкой) → **«Отправить тему ученикам»**;
  - **Отложить** — выход в меню с сохранением черновика в состоянии FSM.
- Навигация **«Шаг назад»** / **«Отмена»** на этапах создания.

### 🗑 Удаление материалов

- **Удалить задание** — выбор **темы** (с пагинацией) → подтверждение.
- Удаление темы **необратимо**: удаляются **все задания** этой темы у преподавателя и связанные **ответы учеников** (прогресс по теме сбрасывается в БД).

### ✅ Проверка ответов

- **Проверить ответы** — выбор группы → задания, по которым есть **непроверенные** сдачи → выбор ученика.
- Просмотр **медиа-ответа** (голос / кружок / видео в зависимости от типа).
- Ввод **оценки от 1 до 5** и **текстового комментария** для ученика.
- После сохранения — возврат к заданию или в меню.

### 👀 Проверенные задания

- Просмотр по **группе** → **заданию** → списку учеников (✅ сдано и оценено / ❌ не сдано или не проверено).
- Детали: тема, задание, описание, **оценка**, **ваш комментарий**.

### 📊 Статистика

- По **группе**: по каждому заданию — **средний балл** по проверенным работам (или «нет оценок»), плюс **общий средний балл** по группе.
- **Список учеников** группы → **успеваемость** по каждому заданию: не выполнено / на проверке / оценка.

## 🛠 Стек технологий

| Категория | Технологии |
|-----------|------------|
| Язык | **Python 3.12+** |
| Telegram | **Aiogram 3** |
| База данных | **MySQL 8**, **SQLAlchemy 2**, **Alembic** (миграции) |
| Контейнеры | **Docker**, **Docker Compose** |
| Логи | **Loguru**, **Graypy** → **Graylog** (стек **OpenSearch** + **MongoDB** в compose) |
| Конфиг | **environs**, драйверы **aiomysql** / **asyncmy** |
| Опционально | Прокси для Bot API (**aiohttp** session) |

## 🐳 Запуск через Docker

### 1️⃣ Файл `.env`

Создайте `.env` в корне проекта. Пример:

```env
BOT_TOKEN=your_telegram_bot_token
ADMINS_ID=123456789

DB_USER=root
DB_PASSWORD=root
DB_HOST=db
DB_PORT=3306
DB_NAME=tbot_db

OPENSEARCH_PASSWORD=StrongPassword123!

PROXY_LOGIN=
PROXY_PASSWORD=
PROXY_HOST=
PROXY_PORT=

GRAYLOG_HOST=graylog
GRAYLOG_PORT=12201
```

### 2️⃣ Запуск контейнеров

```bash
docker compose up -d --build
```

Поднимутся сервисы:

| Сервис | Назначение |
|--------|------------|
| 🤖 **bot** | приложение бота |
| 🗄️ **db** | MySQL |
| 🌐 **adminer** | веб-интерфейс к БД — [http://localhost:8080](http://localhost:8080) |
| 📊 **graylog**, **mongodb**, **opensearch** | централизованные логи — [http://localhost:9000](http://localhost:9000) |

При старте контейнера **бота** автоматически применяются миграции **Alembic**.

### 3️⃣ Логи бота

```bash
docker compose logs -f bot
```

---

## 👑 Администратор (`ADMINS_ID`)

В `.env` укажите числовой Telegram ID (один или несколько через запятую **без пробелов**):

```env
ADMINS_ID=123456789,987654321
```

После изменения `.env`:

```bash
docker compose up -d --build
```

Команда **`/admin`** открывает панель администратора (назначение учителей, рассылки, бан и др.) — только для ID из списка.

## 📌 Полезные команды Docker

```bash
# Остановить сервисы
docker compose down

# Остановить и удалить тома (включая данные БД)
docker compose down -v

# Перезапустить только бота
docker compose restart bot
```

## ⚠️ Заметки

- Токен **`BOT_TOKEN`** должен быть выдан **BotFather** и оставаться секретным.
- В **`ADMINS_ID`** — только **числовые** Telegram ID.
- Если прокси не используется, оставьте **`PROXY_*`** пустыми.
