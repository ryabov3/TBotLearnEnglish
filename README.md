# 🇬🇧 TBotLearnEnglish

Telegram-бот для обучения **произношению английского языка** с удобными ролями для ученика, учителя и администратора.

Сервис помогает выстроить обучение по шагам: учитель создает задания, ученик отправляет ответы в нужном формате, а преподаватель проверяет результаты.

## ✨ Возможности бота

- 🎯 Тренировка английского произношения через структурированные задания.
- 👩‍🏫 Полноценный функционал для учителя: свободное создание тем и различных заданий.
- 📎 Поддержка вложений в заданиях (фото, видео, аудио, документы и др.).
- ✅ Проверка ответов учеников и ведение учебного процесса внутри Telegram.
- 🧩 Гибкая настройка требуемого формата ответа для каждого задания.

## 🎙️ Форматы ответа ученика

Учитель может выбрать, в каком формате ученик должен сдавать ответ:

- 🎤 только аудио/голосовое;
- 🎥 только видео/кружок;
- 🔄 аудио **или** видео (любой из двух форматов).

То есть бот поддерживает ответы: **аудио**, **видео**, а также формат **«аудио или видео»**.

## 🛠️ Стек технологий

- Python 3.12
- Aiogram 3
- SQLAlchemy + Alembic
- MySQL 8
- Docker + Docker Compose
- Graylog (централизованные логи)

## 🐳 Запуск через Docker

### 1) Подготовьте файл `.env`

Создайте `.env` в корне проекта и заполните переменные (пример):

```env
BOT_TOKEN=your_telegram_bot_token
ADMINS_ID=123456789

DB_USER=root
DB_PASSWORD=root
DB_HOST=db
DB_PORT=3306
DB_NAME=tbot_db

OPENSEARCH_PASSWORD=StrongPassword123!

PROXY_LOGIN=
PROXY_PASSWORD=
PROXY_HOST=
PROXY_PORT=

GRAYLOG_HOST=graylog
GRAYLOG_PORT=12201
```

### 2) Запустите контейнеры

```bash
docker compose up -d --build
```

После запуска поднимутся:

- 🤖 `bot` — приложение бота;
- 🗄️ `db` — MySQL;
- 🌐 `adminer` — интерфейс для БД: [http://localhost:8080](http://localhost:8080);
- 📊 `graylog`, `mongodb`, `opensearch` — стек логирования: [http://localhost:9000](http://localhost:9000).

### 3) Проверьте логи бота

```bash
docker compose logs -f bot
```

При старте контейнера автоматически применяются миграции Alembic.

## 👑 Как выдать права администратора

Права администратора задаются через переменную `ADMINS_ID` в файле `.env`.

Один администратор:

```env
ADMINS_ID=123456789
```

Несколько администраторов (через запятую, без пробелов):

```env
ADMINS_ID=123456789,987654321
```

После изменения `.env` перезапустите контейнеры:

```bash
docker compose up -d --build
```

## 📌 Полезные команды

```bash
# Остановить сервисы
docker compose down

# Остановить и удалить тома (включая данные БД)
docker compose down -v

# Перезапустить только бота
docker compose restart bot
```

## ⚠️ Примечания

- Проверьте, что `BOT_TOKEN` валиден и выдан через BotFather.
- В `ADMINS_ID` должны быть только числовые Telegram ID.
- Если прокси не используется, оставьте `PROXY_*` пустыми.
