# TBotLearnEnglish

Telegram-бот для обучения **произношению английского языка** с кабинетом учителя и администратора.

Бот помогает организовать процесс так, чтобы ученики получали задания, отправляли ответы в нужном формате и получали проверку от преподавателя.

## Что умеет бот

- Обучает учеников произношению английского языка через последовательные задания.
- Даёт учителю функционал для **свободного создания различных заданий** (темы, описание, вложения, проверка ответов).
- Поддерживает медиа-вложения в заданиях (например, фото, видео, аудио, документы).
- Позволяет задавать формат ответа ученика:
  - только аудио/голосовое;
  - только видео/кружок;
  - аудио или видео (по выбору ученика).

## Форматы ответов ученика

По условиям задания, ученик может отправить:

- аудио;
- видео;
- аудио и/или видео (если учитель разрешил любой формат).

## Технологии

- Python 3.12
- Aiogram 3
- SQLAlchemy + Alembic
- MySQL 8
- Docker + Docker Compose
- Graylog (централизованные логи)

## Запуск через Docker

### 1) Подготовьте `.env`

Создайте файл `.env` в корне проекта и заполните переменные (минимальный пример):

```env
BOT_TOKEN=your_telegram_bot_token
ADMINS_ID=123456789

DB_USER=root
DB_PASSWORD=root
DB_HOST=db
DB_PORT=3306
DB_NAME=tbot_db

OPENSEARCH_PASSWORD=StrongPassword123!

PROXY_LOGIN=
PROXY_PASSWORD=
PROXY_HOST=
PROXY_PORT=

GRAYLOG_HOST=graylog
GRAYLOG_PORT=12201
```

### 2) Запустите контейнеры

```bash
docker compose up -d --build
```

Что поднимется:

- `bot` — приложение бота;
- `db` — MySQL;
- `adminer` — веб-интерфейс для БД ([http://localhost:8080](http://localhost:8080));
- `graylog`, `mongodb`, `opensearch` — стек логирования ([http://localhost:9000](http://localhost:9000)).

### 3) Проверьте логи бота

```bash
docker compose logs -f bot
```

При старте контейнера автоматически применяются миграции Alembic.

## Как выдать права администратора

Права администратора задаются переменной `ADMINS_ID` в `.env`.

- Один админ:

```env
ADMINS_ID=123456789
```

- Несколько админов (через запятую, без пробелов):

```env
ADMINS_ID=123456789,987654321
```

После изменения `.env` перезапустите бота:

```bash
docker compose up -d --build
```

## Полезные команды

```bash
# Остановить сервисы
docker compose down

# Остановить и удалить тома (включая данные БД)
docker compose down -v

# Перезапустить только бота
docker compose restart bot
```

## Примечания

- Убедитесь, что токен бота (`BOT_TOKEN`) валиден.
- `ADMINS_ID` должен содержать именно числовые Telegram ID.
- Если прокси не используется, оставьте `PROXY_*` пустыми.
